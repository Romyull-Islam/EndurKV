# EndurKV Experimental Program — Wave Roadmap (Waves 1-11)

**Device:** OnePlus 15 / Snapdragon 8 Elite Gen 5 / 12 GB UMA LPDDR5X-9600
**Models:** Llama-3.2-1B-Instruct Q4_K_M, Gemma-2-2B Q4_K_M, Phi-3-mini-128k-Instruct Q4_K_M
**Build:** llama.cpp `07dca62`, CPU-only (4 threads), `n-gpu-layers 0`
**Cell convention:** one "cell" = one (model x policy) trajectory inside a wave session. K-sweep cells count K as the swept axis. Wave 3 spans two sessions (Llama narrative-QA REAL + Phi-3 long-prompt).
