\section*{Contextual bandit against the rule: complete results}

\noindent\textbf{Protocol.} One pull is one real request on the phone: Llama-3.2-1B on the Adreno 840,
9737-token prompt, 1024 output tokens, $K{=}1024$, \muKV\ frozen config. Cooling gate (DDR $\le35$\,\textdegree C,
battery $\le33$\,\textdegree C) before every pull, CPU caps pinned, GPU cap restored after each pull.
Energy is metered from the USB rail plus the coulomb counter. Epsilon-greedy, $\epsilon=0.25$, warm start of
one pull per (context, arm). 24 pulls on 2026-09-03, 11:08 to 13:37.

\medskip
\noindent\textbf{Reward.} $r = w_q - w_t\,T/T_\mathrm{ref} - w_e\,E/E_\mathrm{ref}$ with
$E_\mathrm{ref}=782.0$\,J and $T_\mathrm{ref}=142.4$\,s, the cost table's prediction for this request at
1200\,MHz. The weights are the scheduler's own tier weights, so the bandit optimizes exactly the objective
the rule is built to serve.
